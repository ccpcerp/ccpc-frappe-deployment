## P20A contract currently implemented

`automatic_report_policy.py` accepts a UTF-8 JSON object <=1024 bytes with
exactly these nine fields and closed allowed-value sets:

```
version: 1
environment: DEVELOPMENT
work_type: investigation | code-review | test-review | documentation
status: completed | partial | blocked
change_scope: none | development-code | development-docs
test_status: not-run | static-only | mocked-only | development-live
finding: none | needs-investigation | test-gap | transaction-safety |
         permission-boundary | worker-state | regression-risk
risk: unknown | low | medium | high
approval: none | required
```

The renderer inserts a server-side UTC timestamp and constant, predefined
English report text. It passes the current `report_policy.py` and GitHub
`build_comment()` on tested inputs. The report expresses **agent claims**;
there is no independent evidence, detailed transcript, file references,
verified tests, or production safety assurance.
