## 2. Proposed accounting design — REQUIRES ACCOUNTING APPROVAL

**Recommended valuation basis:** a return of unused identical material should reverse its documented **original posted issue cost** (not an arbitrary current list/standard price). Compute source issue cost from actual submitted Stock Ledger valuation (and its stock-UOM quantity) with a deterministic rule for multiple ledger rows, batches, precision, later reposts and changes in valuation. Cap total return value/quantity per source row and reconcile to its remaining unreversed original consumption amount. If a return must be valued differently to satisfy ERPNext stock valuation behavior, document an explicit **variance account, dimension and approval** instead of silently distorting the original expense. Whether to force the original outgoing unit cost as the incoming receipt rate using supported Stock Entry fields is a **test question**, not assumed verified behavior.

**Recommended account/dimension allocation:** before submitting a return, resolve the exact original issue item's expense-account and cost-center posting, together with its immutable Equipment dimension and original **beneficiary** Department (work_for_department when applicable). Preserve the source issue detail ID and relevant item/stock-UOM and warehouse/company references. The return's expense-credit entry should use that source account and those source dimensions. Do not recompute from current Item defaults, renamed/reassigned Equipment, current Department or Company fallback. Company and approved stockroom destination inventory account must be consistent. Whether Department itself is a registered GL accounting dimension versus represented through an approved Cost Center mapping remains to be inspected/tested in the target configuration.

**Illustration, not test evidence:** 10 bearings issued at 500 per unit: stock inventory credit 5,000; approved consumption expense debit 5,000 to original Equipment and beneficiary cost allocation. Three accepted unused bearings returned at the approved original unit cost: inventory debit 1,500; the **same original expense** credit 1,500 with same allocation; total net expense 3,500 and 7 net units consumed. A later-period return credits expense in its posting period; do not backdate or silently rewrite the original issue.

**Critical prerequisite:** verify/fix the original **issue-side** expense_account, cost_center and Equipment/beneficiary Department mapping in the dedicated branch and tests before asserting that the return can correctly reverse it. An issue posting to a generic default and a return posting to a different account would invalidate per-Equipment/Department reporting even when overall GL balances.

## 3. Proposed stockroom controls — REQUIRES OWNER APPROVAL

- Staff returning materials supplies original Withdrawal Slip reference, item and quantity; records physical handover. Proposal: only designated **Stockroom Personnel** may record/verify physical receipt, and a **different authorized stockroom supervisor/approver** submits a return (subject to mapping existing CCPC roles/permissions; no new role assumed present). The original issuer, preparer, returner and approver relationships require explicit segregation-of-duties agreement.
- Accept **unused, identifiable, serviceable, correct-company stock** into an approved destination stockroom warehouse; capture receiving identity/time and condition, photo/evidence where useful. Damaged, missing identification, scrap, contaminated or serialized/batch exceptions go through separate hold/quarantine and accounting review, not automatically available inventory.
- Source-link each receipt to the exact original submitted **Material Issue detail + Withdrawal Slip item** with immutable source company, Item and stock UOM. A distinct return-source header and child reference must coexist with the old **issue-only withdrawal_slip** rule; do not relax the issue validator into allowing arbitrary submitted receipts against it.
- Allow one or multiple partial returns only up to **issued units minus accepted, non-cancelled returns** (by exact source row). No return against cancelled issues, wrong company, stale warehouse eligibility, invalid UOM or changed source context. Use a unique return request identifier, SQL uniqueness where appropriate, source row lock, atomic submission and post-commit cache refresh for retry safety.
- Derive returned_qty and net_used_qty from submitted linked return vouchers, never user-editable totals. Cancelling a **return** reverses only that return's stock/GL and recomputes its contribution; original issue remains intact. Proposed safe default: **block original issue cancellation while any active return exists**, then use a separately approved reversal order. Do not auto-cascade cancellation.
- Account and valuation overrides must not be open to the ordinary return receiver or be silently altered by Item defaults. A privileged correction/exception path should log reason, creator, approver and source values.

## 5. Remaining policy decisions

**Approved:** Option A — original issuance is consumption, accepted unused return uses a **separately linked Material Receipt** and reduces original Equipment/Department net cost.

**Recommended but not yet approved:** original posted issue-cost valuation (with explicit variance path when necessary); source-linked **same expense-account and Equipment/beneficiary Cost Center** credit; designated Stockroom Personnel receiver plus **independent supervisor submitter**; serviceable-only direct return; multiple bounded partial returns; stop original issue cancellation while submitted returns exist.

**Next operator/accounting sign-off:** confirm expense-account/dimension mapping and valuation/variance approach; identify the authorized receiver and independent approver role(s); agree item condition and exception policy. **DO NOT implement transactional return code, submit stock vouchers, merge app PRs, perform DEV migrations, or touch PRODUCTION yet.**
