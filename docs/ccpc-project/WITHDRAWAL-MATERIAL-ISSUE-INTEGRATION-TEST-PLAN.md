## 2. GitHub source findings and fixture requirements

- `withdrawal_slip_stock.py` exposes `issue_withdrawal_slip` via POST-only whitelist; it requires Stockroom/System Manager role, write permission on the Slip, `Stockroom Review`, `received_by`, valid issue quantities, and a matching parent `SELECT … FOR UPDATE` lock; it builds a new Slip-scoped Material Issue, sets per-document `ignore_permissions`, inserts and submits within a request transaction. It rejects existing drafts or submitted issues. Validation and on-submit hooks run through `ccpcerp/hooks.py`.
- `ccpcerp/setup.py` workflow defines Requestor's **Approve & Send to Stockroom** transition `Draft → Approved` and Stockroom Personnel's **Start Review** transition `Approved → Stockroom Review`; prefer real transition APIs over direct status updates. Requestor self-approval is allowed by the checked source, but must be verified against actual site's workflow before transaction execution.
- `Withdrawal Slip` JSON requires `requestor`, `required_by`, issuing `company`, `source_warehouse`, `department`, `physical_location`, `purpose`, `requesting_company` and at least one `items` row; it also has read-only `approving_supervisor` and `status`, and optional `section`, `equipment`, `job_order`. Controller defaults `approving_supervisor` to authenticated creator and checks department-company and optional section consistency.
- Before creating records, **read-only verify** a suitable active non-group Department in fictional requester `Integration Test Requester (TREQ)`, role permissions and optional section requirements; issuing `Integration Test Issuer (TISS)` and leaf `Stores - TISS`; enabled synthetic stock item and exact expected valuation/expense/cost-center settings. Do not invent or change missing fixture masters without separate approval.
- Minimum proposed users (names are **proposals, not created**): one dedicated fictional System User with only `Withdrawal Slip Requestor` plus non-privileged unavoidable Frappe desk roles, and one fictional System User with only `Stockroom Personnel` plus unavoidable non-privileged desk roles.
