## 2. GitHub source findings and fixture requirements

- `withdrawal_slip_stock.py` exposes `issue_withdrawal_slip` via POST-only whitelist; it requires Stockroom/System Manager role, write permission on the Slip, `Stockroom Review`, `received_by`, valid issue quantities, and a matching parent `SELECT … FOR UPDATE` lock; it builds a new Slip-scoped Material Issue, sets per-document `ignore_permissions`, inserts and submits within a request transaction. It rejects existing drafts or submitted issues. Validation and on-submit hooks run through `ccpcerp/hooks.py`.
