## Approved source changes

1. **`ccpcerp/ccpc_erp/ci_finance_setup_connection.py`**, blob `ca3002bdfc6551cec1b5a6f82a133fcd3ee1bc58`. Context manager first invokes `assert_finance_disposable_site()`, saves the original thread-local Frappe DB/session/site, opens a distinct `frappe.connect(set_admin_as_user=False)` connection and confirms its identity, active site and `SELECT DATABASE()` against configured `frappe.conf.db_name`. The worker body uses the **new independent connection**. On exit it rolls back any remaining child transaction, closes only the child, restores the caller's original DB and user. A reviewed fail-closed fix sets `isolated_db=None` if `connect()` unexpectedly reused the original; that path **must not roll back or close the caller**. It never commits by itself.
2. **`ccpcerp/ccpc_erp/ci_finance_master_bootstrap.py`**, blob `92f40132dbfaebc7b202e86ce81a56241aeff00f`. An **opt-in, never auto-wired** test-only bootstrap. Before any DB operation its gate requires exact Finance CI site/org/repo/branch/job/SHA, independent environment flags **`CCPC_ALLOW_FINANCE_MASTER_BOOTSTRAP=isolated-only`** and **`CCPC_ALLOW_FINANCE_MASTER_COMMIT=isolated-only`**, `allow_tests`, MariaDB and isolated bench Administrator. In a fresh independent connection it refuses existing `_Test Company` or unexpected `Stock Adjustment - _TC` and requires `All Item Groups`. It creates **only** the canonical fictional Company using selected pinned ERPNext test-record fields, relying on ERPNext's Company controller to generate the standard test CoA; a dedicated **read-only** `verify_finance_master_records()` requires exact Company abbr/currency/country and an enabled, non-group Expense Account attached to it. If not present it raises rather than writing a fabricated Account or submitting an invoice/Stock Entry. A separate opt-in SQL `commit()` applies only to its child connection. This is **provisional source code** and controller CoA generation is not runtime-proven.
3. **Updated `ccpcerp/ccpc_erp/ci_finance_race_fixture.py`**, blob `b277213e3757359ef17aaf6b9ffc177808e0dcde`. ## Residual risks, controls, and status

- **Unknown ERPNext controller behavior:** Real Company insertion and generated chart of accounts, required Item Group root, Country/INR master dependencies, implicit DB commits, framework hooks, background jobs/mail/side effects and user Role/User Permission controllers are not verified in a live ephemeral Frappe/ERPNext v16 instance.
